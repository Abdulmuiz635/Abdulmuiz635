### Hi, I'm Abdulmuiz 👋

I build AI systems that turn security and threat data into decisions people can act on. My work spans **threat intelligence, detection engineering, and the AI tooling that modern threat operations run on**, moving raw data through ingestion, normalization, enrichment, and detection, then layering models on top that analyze cases and drive response.

What I care about most is output that holds up when a real decision is on the line. A confident wrong answer in security is worse than no answer, so most of my work is about the verification and evaluation layer around a model, not just the model itself.

```yaml
role:      AI Security & Threat Intelligence Engineer
focus:     [ detection engineering, MLSecOps, CTI, AI security ]
building:  AI-augmented threat intel + detection pipelines
learning:  adversarial ML, agent security, evaluation frameworks
mindset:   "verify before you trust the output"
```

---

### 🔭 What I'm working on

- **Detection engineering** that does not fire on a normal Tuesday — Sigma rules, multi-signal correlation, and honest false-positive tuning.
- **AI-native SOC pipelines** — Kafka ingestion, ECS normalization, CTI enrichment, MITRE ATT&CK mapping, feeding models that triage and investigate.
- **Agent security** — the guardrails between an AI agent and a live system, so nothing it proposes acts without a human and an audit trail.
